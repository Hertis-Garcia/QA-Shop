# QA-Shop

QA-Shop is a small e-commerce web application developed as a Software QA portfolio project.

The project demonstrates the software development and QA lifecycle from requirements and development through manual testing, API testing, test automation, defect tracking, regression testing, and CI/CD.

## Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express

### Database
- SQLite
- Prisma

### Authentication
- JWT

### Testing
- Postman
- Playwright

### Version Control
- Git
- GitHub
